# DAYMATE

대학생·청년을 위한 일상 여가 동행 웹 서비스 **시제품**입니다.

> “가고 싶은 곳은 있지만 함께 갈 사람의 일정과 취향이 맞지 않아 활동을 미루는 상황”을 해결합니다.
> 새로운 취미를 제안하지 않고, 야구 직관·성수 팝업·전시 관람처럼 **이미 하고 싶은 활동**에 맞는 동행을 연결합니다.

- 예시 그룹(14개)·예시 참여자(14명)·가상 학교·일정은 **모두 허구**입니다. 실제 경기·전시·공연 일정이나 예약 가능 여부와 무관합니다.
- 특정 구단·브랜드의 공식 서비스가 아니며, 로고·사진·실존 인물 프로필을 사용하지 않습니다. 이미지는 모두 직접 만든 SVG 일러스트입니다.
- 서버가 없는 시제품이라 모든 상태는 **브라우저 localStorage**에만 저장되고, 다른 사용자와 공유·전송되지 않습니다.

## 실행 방법

Node.js 20.19 이상 (22 권장)

```bash
npm install
npm run dev        # 개발 서버 http://localhost:5173
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 미리보기 http://localhost:4173
npm test           # 단위 테스트 (Vitest)
npm run test:e2e   # E2E 테스트 (Playwright, 모바일 375px + 데스크톱)
```

E2E 테스트를 처음 실행하는 환경이라면 `npx playwright install chromium`이 필요할 수 있습니다.

## Vercel 배포

| 항목 | 값 |
| --- | --- |
| Framework Preset | Vite |
| Root Directory | `./` (저장소 루트, 비워 두면 됨) |
| Install Command | `npm ci` |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Node.js | 20.x 이상 (22.x 권장) |

위 값은 `vercel.json`에도 들어 있어 대시보드에서 따로 바꾸지 않아도 됩니다.

라우팅은 HashRouter(`/#/explore`)를 사용합니다. 해시 주소는 서버에 항상 `/`로 요청되므로 새로고침해도 404가 나지 않습니다.
`/explore`, `/groups/g01`처럼 해시 없는 주소로 직접 접속하는 경우를 위해 `vercel.json`이 모든 경로를 `index.html`로 재작성하고,
앱이 시작될 때 같은 화면의 해시 주소(`/#/explore`)로 바꿉니다. 자산은 절대 경로(`/assets/...`)로 빌드되어 깊은 경로에서도 정상 로드됩니다.
하위 경로에 배포하는 다른 호스팅에서는 `VITE_BASE=/하위경로/ npm run build`로 빌드하세요.

## 핵심 규칙

### 5가지 동행 성향 (각 0·50·100 저장)
동행 인원 / 교류 방식 / 활동 속도 / 계획 방식 / 지출 성향. 학교·나이·관심 활동·날짜는 별도 정보로 받습니다.
5문항을 모두 답해야 결과가 확정되며, ‘결과 수정’ 중에는 다시 확정할 때까지 기존 결과로 추천합니다.
검증된 심리검사가 아니며 “동행 선호 프로필”로만 표시합니다.

### 그룹 추천 (`src/lib/matching.ts`)
1. **필터**: 관심 활동, 가능한 날짜·시간대, 예산 상한, 잔여 인원, 활동별 필수 조건(‘맞아야 추천’), 차단 여부, 지난 일정
2. **정렬**: `성향 근접도 = 100 − 5개 성향 값 차이의 평균` 내림차순 (동점은 빠른 날짜순)
3. ‘성향 근접도 85/100’ 형식으로만 표시 (확률·만족도 표현 사용 안 함)
4. 추천 이유(같은 축 문장 + 날짜·예산 조건), 상세 화면에서 차이가 큰 축 안내
5. 결과가 없으면 제외 사유별 개수와 조정 방법 안내

활동별 조건은 `src/data/categories.ts`에 정의되어 있으며 ‘맞아야 추천(required)’과 ‘참고 정보(preference)’로 나뉩니다.
‘상관없음/팀 무관’은 어떤 값과도 맞는 것으로 봅니다.

### 역매칭 (`src/lib/actions.ts`)
- 역매칭 프로필 공개는 **기본값 꺼짐**, 명시적으로 동의해야 후보가 됨 (내 프로필 포함). 철회 시 대기 중 초대 자동 취소
- 후보 조건: 공개 동의, 관심 활동, 날짜·시간대, 예산, 필수 조건, 차단 아님, 이미 멤버·대기·수락·거절 상태 아님 → 근접도순
- 중복 초대 방지(대기·수락 중), 거절한 참여자 재초대 불가, 취소한 초대는 다시 초대 가능
- 수락해야 참여 확정, 수락 시 멤버·정원 반영, 정원이 차면 초대·추가 수락 차단
- 차단 관계에서는 후보·초대·수락 모두 차단, 차단 시 관련 대기 초대 자동 취소
- 프로필에 학교 이메일·전화번호·학번을 노출하지 않음
- 시연: 내가 만든 그룹 + ‘시연용 예시’ 그룹(3개)의 호스트 역할을 체험하고, 참여자 화면에서 예시 참여자 시점으로 수락·거절

### 안전 장치
- **대학생 인증 체험 모드**: 가상 학교 선택 → 승인 도메인(`*.ac.example`)만 허용 → 화면의 ‘체험용 메일함’으로 6자리 코드 전달(5분 유효, 5회 제한) → 검증. 이메일·코드는 저장하지 않으며 결과는 “체험 완료 · 실제 인증 아님”으로만 표시합니다. 재학 상태 추가 확인은 실제 연동이 필요하다고 안내합니다.
- **만남 안내**: 첫 만남은 공개 장소, 시간·비용·해산 계획 사전 공개, 추가 구매·뒤풀이·사진 촬영은 본인 선택 (참여 요청 시 확인 체크)
- **신고·차단**: 그룹·회원 신고(사유 필수, 추가 설명), 차단 즉시 추천·둘러보기·역매칭 제외, 차단 해제. 신고는 운영자에게 전달되지 않으므로 처리 상태를 “미전송(이 브라우저에만 기록)”으로 표시합니다.
- 사용자 입력은 React 텍스트 노드로만 렌더링하며 `dangerouslySetInnerHTML`을 쓰지 않습니다. 제어 문자 제거·길이 제한 적용.

## 브라우저에 저장되는 상태
`localStorage['daymate:prototype:v1']`: 테스트 결과·선택 조건, 역매칭 공개 동의, 저장한 그룹, 생성한 그룹, 참여 요청, 초대·수락·거절 상태, 신고·차단 기록, 인증 체험 여부(학교 id만).
푸터의 ‘시제품 데이터 초기화’로 모두 지울 수 있습니다. 손상된 값은 기본값으로 복구합니다.

## 검증
- `npm test` — 27개 단위 테스트: 근접도 계산, 5문항 미완료 시 미확정, 결과 수정 반영, 필터(활동·날짜·시간·예산·조건·차단), 정렬, 역매칭 동의/중복 초대/정원/거절·취소/차단, 신고, 그룹 생성 검증, 저장소 복구
- `npm run test:e2e` — 46개 E2E 테스트 (모바일 375px, 데스크톱 1280px): 실제 화면에서 위 흐름 전체, XSS 입력, 13개 화면 가로 넘침·터치 영역(40px 이상), 모달 화면 내 표시·Esc 닫기·포커스 가두기/복귀, 키보드 문항 선택, 해시 없는 경로 직접 접속·새로고침

## 실제 운영 시 연결이 필요한 기능
| 기능 | 시제품 | 운영 시 필요 |
| --- | --- | --- |
| 회원·데이터 저장 | localStorage | 인증된 계정, 서버 DB, 권한 검사(호스트만 초대 등 서버 측 검증) |
| 학교 인증 | 체험 모드(화면 코드) | 학교별 승인 도메인 목록 관리, 메일 발송 서비스, 코드 해시 저장·만료·재시도 제한, 재학 상태 확인 연동 |
| 참여 요청·초대 | 같은 브라우저 내 기록 | 실시간 전달(푸시·알림), 호스트 승인 흐름, 동시 수락 시 정원 트랜잭션 처리 |
| 신고 | 로컬 기록만 | 운영자 검토 도구, 처리 상태 갱신, 증거 보관 정책, 긴급 대응 절차 |
| 차단 | 로컬 기록 | 서버 측 양방향 차단 적용 |
| 일정·장소 | 허구 예시 | 실제 경기·전시·공연 일정 확인, 예약은 공식 판매처 안내 |
| 개인정보 | 학교 이메일·학번 미수집 | 개인정보 처리방침, 최소 수집·보관 기간, 역매칭 공개 범위 동의 이력 |
